# cosmosishood

`cosmosishood` is a Python package for cosmology and likelihood workflows.

## Installation

Install the package from the repository root:

```bash
python -m pip install .
```

## Usage

```python
import cosmosishood

print(cosmosishood.__version__)
```

The package is currently a minimal scaffold; add domain-specific functionality
to `src/cosmosishood/` as the project develops.
